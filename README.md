# Music Artist Discovery System

## Overview
This project identifies emerging music artists using Spotify data. It ranks artists based on popularity, followers, and growth trends, and provides actionable insights for music platforms, labels, and talent agencies.

## Features
- Fetch artist data using Spotify API
- Clean and preprocess raw data
- Exploratory Data Analysis (EDA) on popularity and genre trends
- Emerging Artist Score to rank promising artists
- Interactive dashboard for visualization

## Tools & Technologies
- Python (Pandas, Spotipy, Matplotlib, Seaborn)
- Power BI / Tableau
- Git & GitHub for version control

## Folder Structure
- `data/` : raw & cleaned CSV files
- `notebooks/` : Jupyter notebooks for each analysis step
- `src/` : reusable Python scripts
- `dashboard/` : dashboard file
- `docs/` : reports & business insights

## Usage
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Run `notebooks/01_data_collection.ipynb` to fetch data
4. Proceed with cleaning, analysis, and dashboard creation

## Business Value
Helps record labels and music agencies identify rising artists early, optimize investments, and discover trends in the music market.
